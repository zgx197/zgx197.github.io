# Patents Honor Assets

这个目录用于存放“一级专利发明人相关资料”对应的补充图片素材。

目录结构：

- `images/`: 页面自动扫描并展示的专利相关截图

建议放入的内容：

- 专利证书截图
- 专利公开号或授权公告页截图
- 作为第一发明人的相关证明截图
- 其它适合在简历页面公开展示的专利成果材料

命名建议：

- 推荐使用两位数字前缀控制展示顺序，例如 `01-专利证书.png`
- 如果文件名前两位不是数字，页面会回退到默认文件名顺序

页面行为：

- `src/data/honor-extras.ts` 会自动扫描 `public/honor-assets/patents/images/`
- 只有存在图片时，`/resume` 页面才会显示“荣誉相关图片”区块
- 图片标题默认由文件名生成
