# Honor Asset Layout

本地荣誉补充素材统一放在 `public/honor-assets/` 下。

当前目录：

- 专利与知识产权相关截图: `public/honor-assets/patents/images/`

通用约定：

- 页面会自动扫描各荣誉目录下的 `images/` 图片文件并在 `/resume` 渲染。
- 支持格式：`png`、`jpg`、`jpeg`、`webp`、`gif`、`avif`
- 如果文件名前两位是数字，例如 `01-专利证书.png`，会按这两位数字排序。
- 如果前两位不是数字，则按默认文件名顺序显示。
- 每个荣誉目录建议维护自己的说明文档，用来记录该目录放什么素材、如何命名。
